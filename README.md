# StudySprint — Personal Study Coach

A beginner-friendly, mobile-first prototype for the Alexa+ simulated-experience track of the Build, Ship, Shape: Amazon Developer Hackathon.

## What it does
- Accepts topics, available study time, goal, and an optional deadline.
- Creates a three-step study workflow: focus, practice, and recall/review.
- Tracks completed tasks and recommends the next action.
- Saves the current plan locally in the browser using localStorage.
- Does not send user-entered data to a server.

## Important scope note
This is a prototype of a simulated Alexa+-style experience, not a real Alexa+ integration and not an official Amazon product. Before submitting, verify that the project and demo satisfy the current official hackathon rules. The hackathon requires a code repository, a demo video under three minutes, and product feedback.

## Run on Android
1. Open `index.html` in a browser, or host the file using a static hosting service.
2. Enter at least one subject, select study time and goal, then tap **Create my plan**.
3. Mark tasks complete, tap **What next?**, and refresh the page to test local progress persistence.

## Demo script (under 3 minutes)
1. Introduce StudySprint and the student problem (15 seconds).
2. Enter three topics, choose 60 minutes and an exam goal, then create a plan (35 seconds).
3. Mark one task complete and show the coach's next action (30 seconds).
4. Refresh the page to show saved progress (15 seconds).
5. Explain the workflow and limitations honestly (20 seconds).
